# Беларуская мова ў эпоху ШІ

Вэб-прэзентацыя Аляксея Картынніка для лінгвістаў, 16 слайдаў.

**Прэзентацыя:** https://itbeard.github.io/bel-conf-preso-2026/

## Выступ

- Адкрыйце прэзентацыю, націсніце **F** для поўнага экрана.
- **← / → / Прабел** пераключаюць слайды. **O** адкрывае агляд, **N** — нататкі, **S** — крыніцы, **T** — таймер.
- Прыклады з токенамі і кантэкстам запускаюцца і паўтараюцца аўтаматычна. Самі слайды аўтаматычна не пераключаюцца.
- Кнопка **Анімацыя** дазваляе прыпыніць рух. Сістэмная налада змяншэння руху ўлічваецца пры запуску.
- Нататкі адкрываюцца на тым самым экране. Выкарыстоўвайце іх для падрыхтоўкі.
- На тэлефоне працуюць кнопкі і гарызантальныя рухі пальцам. Друк у браўзеры захоўвае ўсе слайды.

## Падвойнае плясканне

1. Адкрыйце **Мікрафон** і націсніце **Уключыць мікрафон**.
2. Дазвольце доступ у браўзеры, пачакайце 2 секунды ў цішыні.
3. Плясніце двойчы з паўзай прыкладна 0,4 секунды. Індыкатар пацвердзіць распазнаванне. Пакуль акно адкрыта, пераходаў няма.
4. Пры патрэбе змяніце адчувальнасць. Праверце яе з месца выступу, потым зачыніце акно.
5. Падвойнае плясканне пераключае на наступны слайд. **Shift+M** адразу выключае мікрафон.

Гук апрацоўваецца лакальна праз Web Audio / AudioWorklet, не запісваецца і нікуды не адпраўляецца. Патрэбны HTTPS або localhost. Фільтр высокіх частот, парог адносна фонавага шуму, кароткая працягласць гуку, інтэрвал 220–700 мс і паўза пасля пераходу памяншаюць памылковыя спрацоўванні. Гэта эўрыстычны дэтэктар рэзкіх гукаў, ён можа рэагаваць на два іншыя рэзкія гукі. Рэха, гукавая сістэма, мікрафон і адлегласць патрабуюць рэпетыцыі ў зале. Праверка рэальнага мікрафона ў зале не праводзілася.

## Лакальны запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Адкрыйце http://127.0.0.1:4173/. Зборка і ўсталяванне залежнасцяў не патрэбныя. Усе рэсурсы прэзентацыі, уключна з QR-кодам і партрэтам, захоўваюцца лакальна. Вонкавыя спасылкі патрабуюць інтэрнэту.

## Файлы і праверка

- `index.html` — змест слайдаў.
- `css/style.css` — афармленне, мабільная версія і друк.
- `js/data.js` — нататкі і крыніцы.
- `js/app.js` — навігацыя, анімацыі, кіраванне мікрафонам.
- `js/clap-worklet.js`, `js/clap-detector.mjs` — апрацоўка гуку.
- `assets/presentation-qr.svg` — QR-код на кананічную спасылку прэзентацыі.

```sh
node --test tests/clap-detector.test.mjs
node --check js/app.js
```

Колькасныя тэсты дэтэктара выкарыстоўваюць сінтэтычныя сігналы і не замяняюць рэпетыцыю з мікрафонам.

Крыніцы пазначаныя на слайдах і ў акне «Крыніцы». Абнаўленні каманд датаваныя 24.09.2026. Публічныя матэрыялы аддзяленыя ад паведамленняў куратараў. Неапублікаваны рукапіс SQARB і перададзеныя скрыншоты не ўваходзяць у рэпазіторый. Партрэт: itbeard.com.
